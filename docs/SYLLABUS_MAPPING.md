## Guardrails

- A syllabus topic is not considered implemented solely because a library is imported.
- Models require a defined target, valid inputs, and suitable evaluation.
- Recommendations may use content-based similarity when no reliable outcome labels exist.
- If the data cannot support a listed algorithm, document the limitation and discuss a suitable educational demonstration with the user before substituting data.
