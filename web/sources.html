What the data can tell you

Venture Insight combines company financial snapshots, startup funding events, and supplemental company-profile claims. It is a source-bounded research index, not a complete list of every startup. A funding event is not revenue, profit, valuation, or proof that a company is still operating.

Global startup sample: quality checks

The pinned raw file contains 20,227 unique round IDs and 11,853 imported Fliar profile-level entries. The app groups rounds by profile path for recommendations, and keeps event rows separate in the funding explorer. The sample has 20,069 rows with a sector, 20,186 rows with a country and 19,939 rows with a news excerpt; a news excerpt can describe a financing announcement rather than the startup's full product. Only 15,951 round amounts are marked verified in this snapshot. Undisclosed, unchecked and failed-check amounts are not displayed as verified figures.

To restore the local data file in a fresh clone, run python3 data/download_global_startup_funding.py. The downloader fetches a pinned upstream commit and verifies SHA-256 before writing. The raw sample is omitted from this repository; the license notice and downloader are included.

Sources reviewed but not imported

  • Accelerator portfolio aggregator reports 21,000+ companies across seven programs and includes descriptions, but it says to respect each provider's terms. The right to redistribute the combined records was not clear enough to copy them into this app.
  • UK Companies House requires API credentials and lists registered entities, not startups specifically.
  • SEC EDGAR provides US public-filer submissions and XBRL facts, not a global/private-startup catalog; SEC APIs also do not support browser CORS.
  • GLEIF LEI data is CC0 global legal-entity reference data, but an LEI does not identify a startup and many businesses have no LEI.
  • OpenCorporates API has access and third-party distribution restrictions; no API key or external-distribution rights were obtained.
